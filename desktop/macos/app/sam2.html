SAM 2 tracking

Select an object on one frame and let SAM 2 follow it through the next frames. Everything runs on this Mac.

One-time setup

SAM 2 needs PyTorch and a model file. They are downloaded once (about 1 GB in total, most of it PyTorch) and stored in this app's data folder. Your annotations and images are never uploaded.

Sources: PyTorch from the Python Package Index, model from Hugging Face (checksum verified).

Track an object

First save your work in CVAT (Ctrl+S): only saved objects can be tracked.
